# UI Bag

This repo hosts a few upcoming, rather interesting utilities for UI/UX on web. Currently:

- macOS' collection multiselect logic
- Scrollview

These are all dependency-less, framework-agnostic, and highly polished for both readability, stability and performance (a tricky sweet spot!).

Regarding the scrollview: the code logic's in the `render`. But the surrounding logic of state management and scheduling are rather interesting too; upon request, I can dive more into the details. Feel free to ping me somewhere and/or file an issue with your questions!

# Demo

Open index.html locally (no server needed!).

# Usage

Copy/paste/modify at your own desire for now since these are meant to be adapted into your project rather than modeled as dependency.
