# Photo Gallery Level 0 Oracle Contract

The final ready reports should prove:

## `navigation-hash-sync`

- line mode still open
- focused image id matches expected target
- hash matches focused image
- scroll lock stays active

## `dismiss-to-row`

- line mode closed
- focused row restored into view
- restored row lands with about `40px` above it

## `caption-selection`

- selected text equals the full caption text
- line mode did not open

## `grid-occlusion`

- mounted count is lower than total photo count

Do not use a report that only proves page boot.
